# Video Forge — 使用指南

当用户问怎么用这个视频插件（"怎么用""帮我做视频"等）时使用本技能。用用户的语言回答。用户没问时，不要主动给出这份指南。

## 回答方式

1. **先诊断**。调用 `video_status`（不带参数）读实时状态：插件是否启用、默认供应商/模型、本会话 chip 的选择（`selection`）、各供应商 key 是否已设置、可用模型、当前工作区的清单/权限/角色。
2. **再给最多三条下一步**，针对诊断结果。不要一股脑全讲，用户追问了再展开。
3. **只答用户问的那一块**。问费用就讲费用，问续拍就讲 `from`。

## 上手三步

1. **配置供应商和 key**。打开插件设置（侧栏 → 插件 → Video Forge），添加供应商（火山方舟 Seedance、MiniMax 或 OpenAI 兼容中转站），填 API key。这一步模型替用户做不了。
2. **在项目工作区里开对话**。工作区就是视频项目，成片落在 `renders/<镜头>/vNNN.mp4`。
3. **直接说要什么**。例如："生成一段 5 秒的海上日落，广角镜头，海浪轻拂。"

## 对话栏的「视频模型」chip

输入框右下角有个视频模型 chip，用户可以在里面给**当前会话**挑供应商/模型、时长、分辨率、画幅，不用每次说。

- 优先级：`video_generate` 的显式参数 > chip > `video-project.yaml` 的 `defaults` > 插件设置。用户说"这一条用 X"仍然优先于 chip。
- chip 是**会话级**的：新开一个对话就回到清单/设置的默认，不会串味到别的片子。
- 用户换了模型时，chip 会清掉新模型不声明的那几项并提示；如果 chip 里的模型已被从设置里删掉，chip 会标红，生成会被拒绝并点名是 chip 的原因——这时让用户点回「自动」，或你自己在对话里显式传参。
- chip 里没有 `mode`（t2v/i2v/...）：输入形态由素材决定，只能由参数或素材决定，不该做会话默认。

如果 `video_status` 报告某供应商没 key，让用户去插件设置里填，别假装你能填。

## 能做什么（附示例话术）

- 一句话出片："做一段 5 秒的……视频"
- 让素材动起来："让 materials/cat.png 里的猫转头看镜头"（拖进对话的文件也能用，传你看到的路径）
- 迭代 / 续拍："镜头 3 再亮一点"，或"接着上一段往下拍"（后者用 `from`，仅方舟 Seedance 支持）
- 嵌进更大的任务：做网页或 PPT 时生成一段视频素材，成片落在工作区
- 问花费："这个项目的视频一共花了多少？"（是估算，见下）

## 看视频 / 展示视频（重要）

片子有三处能看，都在界面里，**都不需要你做任何事**：

1. **对话里的生成卡片**：生成完成后自动出现，自带播放器。用户说"给我看视频""展示一下"，先指向它——"看上面的生成卡片，点播放即可"。
2. **右侧栏的「视频」面板**：本项目所有成片的清单，按镜头分组、最新的默认展开。对话里的卡片会被折叠进"过程"，用户翻找时这个面板是常驻入口（右侧栏「+」→ 视频）。打开之后卡片上还有「在侧栏看全部」。
3. **文件查看器**：卡片上「在文件查看器打开」、面板行上的同名按钮、以及对话里出现的 `renders/.../vNNN.mp4` 路径，都会在右侧栏里直接播原片，可以拖进度条。

**如果这个对话里没有卡片**（用户新开了会话，或要预览之前生成的片子），用 `video_status` 报路径与状态，并告诉用户"右侧栏 → 视频里能看"，不要试图自己把视频"放"到对话里。

**绝对不要**用下面这些方式"代替"播放器，DSH 前端都不支持或会走样：

- 不要写 markdown 里的 `<video>` 标签——DSH 前端不渲染 `<video>`，只有图片是内置的；
- 不要转 GIF、不要抽帧拼图——那只是降级，原片就在上面三处里。

只有当卡片显示"已从保存位置移走或删除"时，才说明文件被用户动过了，需要处理。

## 做不到的事

- 不能按分镜批量生成——一次一个镜头、一次一条视频。
- 不能把多段拼接成片——没有剪辑/拼接，去插件外做。
- 不能用 `from` 续拍 MiniMax 或中转站的成片——只有方舟 Seedance 返回尾帧，改用 `first_frame` 传图。

## 相关要点（该提时再提）

- 每次生成都花钱，消耗真实供应商配额。
- 金额是估算：用量 × 价格表，标注"估算，以供应商账单为准"。真实账单只在供应商控制台。
- 价格表默认从公网价格源（LiteLLM 的公开价目文件 ×7.0 汇率）自动获取，按分辨率分档。拿不到时依次退回上次缓存、内置快照；结果里的 `price_source` 会说是哪一层（`remote` / `cache` / `bundled` / `none`）、多少天前、以及 `last_error`。看到 `cache` / `bundled` 或 `last_error`，就要据实说明"这个数是按旧价估的"，不要当成今天的价报给用户。没有价格行的模型只报"无法估算"，不要用别的模型的单价顶替。
- 超时或重启后查 `video_status`，**绝不要重复提交**——已发出的任务可能正在跑、正在计费，重复提交会被拦截。
- 成片在 `renders/<镜头>/`，旁边 `vNNN.json` 记录它是怎么做的。
- 项目级设置（默认模型 / 分辨率 / 风格 / 角色）在 `video-project.yaml`，不在插件设置里。

## 工具调用失败时

失败是对动作的回应，不是上课——仍要讲清怎么修："没配置供应商"指向插件设置；"只读会话"让用户允许写入；"内容审核拒绝"改提示词或素材，别重发。
