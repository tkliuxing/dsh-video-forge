为什么 1 + 1/4 + 1/9 + … = π²/6

目标Σ 1/n² = ?
前几项1 + 0.25 + 0.111 + 0.0625 + …
衰减1/n² 比 1/n 快得多
前 100 项≈ 1.6350
欧拉 1734π²/6 ≈ 1.6449
几何 ↔ 算术π 与整数平方搭上的桥
正弦乘积sin x / x = Π (1 − x²/(n²π²))
比较系数x² 项：1/6 = Σ 1/(n²π²)
结论Σ 1/n² = π²/6
部分和S₄ ≈ 1.4236
收敛加得越来越慢
尾巴Σ_{n>N} 1/n² ≈ 1/N
